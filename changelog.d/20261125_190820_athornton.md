### Bug fixes

- The Seestar driver now resolves a hostname in `host` (such as `seestar.local`) to an IP address. seestarpy accepts only IP addresses, and with a hostname it silently sent nothing.
- The Seestar driver sets the sub-frame exposure without seestarpy's `expert_mode` flag, which firmware 9.75 rejects with code 109 ("unexpected param").
