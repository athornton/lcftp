### New features

- `lcftp export` writes an observation plan as CSV that N.I.N.A.'s Simple Sequencer can import (Telescopius-format headers) and that observers can read and adapt for any telescope. Each target is named with a target tag such as `lcftp-3f9a1c2e-007`.
- `lcftp ingest DIR` copies FITS frames taken with observers' own software into the spool, matching them to plan items by the target tag in the file name or `OBJECT` header, and queues them for `lcftp upload`. Originals are never changed.
- `lcftp ingest --final --plan ID` records each item of a plan as observed or skipped once the observer has ingested everything; `lcftp status` lists plans awaiting it.
- The client now archives every plan it fetches, so frames can be ingested for plans that are no longer current.
- New observer guide, `docs/observers.md`.
