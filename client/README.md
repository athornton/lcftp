# lcftp-client

Observatory-side client for LCFTP. Part of [Los Cumbres For The People](https://github.com/athornton/lcftp).

Observers whose telescopes the client can't drive can export plans as
CSV (importable by N.I.N.A.) and send frames back: see
[Observing an lcftp plan with your own software](../docs/observers.md).
